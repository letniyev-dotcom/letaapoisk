# летаа — мобильный браузер (Kotlin + Jetpack Compose)

Реально работающий Android-браузер: адресная строка, живой поиск,
безграничный просмотр страниц через `WebView` (движок Chromium) и «сжечь
всё» (полная очистка cookies/кэша/истории).

## Что внутри

- **Домашний экран** — градиентный вордмарк «летаа» (шрифт Onest),
  поисковая строка со скруглёнными (не круглыми) углами, кнопка-огонёк.
- **Поиск** — системная клавиатура, реальная (не выдуманная) история
  запросов в `SharedPreferences`.
- **Результаты** — реальные данные официального открытого MediaWiki
  Search API Википедии (без ключей и скрапинга) + карточка «искать в
  интернете», открывающая настоящую живую выдачу DuckDuckGo в WebView.
- **Страница** — полноэкранный `WebView`, ничего не обрезает контент
  сверху/снизу; плавающая пилюля (назад / домен+замок / обновить /
  поделиться) прячется при скролле.
- **Огонёк** — стирает cookies, WebStorage, кэш приложения и всю историю
  поиска, с анимацией пламени.
- Переходы — те же механики push/свайп-назад/predictive back, что в
  проекте Pace (`PushOverlay.kt`, `ElasticOverscroll.kt`).

## Сборка

Локально:

```bash
./gradlew assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

В GitHub — просто запушьте в `main`/`master` (или запустите workflow
вручную): `.github/workflows/release-apk.yml` соберёт подписанный APK и
приложит его к запуску (Actions → Artifacts).

Подпись release-сборки уже в репозитории: `app/letaa-release.jks`
(alias `letaa`, пароль `letaa2026release`) — только для тестовых сборок,
замените на свой ключ перед публикацией в Google Play.
